# Bear Home Management Stable BearTrack Rebuild

Use this as the new stable base.

Files:
- index.html = public website/homepage. Original design preserved.
- app.html = BearTrack portal/app.
- styles.css = public website styling.
- script.js = mobile nav.

Included:
- Header corrected to BEAR HOME MANAGEMENT.
- Call button resized.
- Remaining visible Bear Maintenance wording removed from website.
- Powered by BearTrack™ retained.
- Phone number retained.
- BearTrack Portal button added to public site.
- BearTrack role views in app.html: Customer, Operations, Technician, Inspection, Admin, History.
- Customer can add profile/home/service/work order/photos.
- Ops can edit accounts/work orders, suggest schedule, change status, move complete work to history.
- Inspection workflow restored as a standalone module inside app.html.

Testing:
1. Deploy the ZIP.
2. Confirm homepage design still matches the approved design.
3. Open /app.html.
4. Add a customer profile.
5. Add a work order.
6. Open Operations and confirm it appears.
7. Edit the record.
8. Mark complete and confirm it moves to History.
9. Open Inspection and confirm the left sidebar/detail panel inspection layout exists.
