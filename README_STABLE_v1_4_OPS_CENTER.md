# BHM Stable v1.4 — BearTrack Ops Center

This patch focuses on the internal BearTrack Ops side only.

## Added
- Inspection-mode inspired Ops Center layout
- Interactive schedule board with drag/drop lanes
- Customer lookup and edit account modal
- Work order create/edit/assign/status controls
- Technician support dashboard and availability controls
- Payments/billing support view using safe payment profile fields only (last 4/status; no full card storage)
- Role tier selector: Admin, Operations, Technician
- Completed work orders move to History
- Inspection mode can create follow-up work orders and recommend membership
